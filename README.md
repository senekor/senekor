  a Jujutsu tutorial for people with little to no prior VCS experience
- [Rust for Embedded Developers](https://www.zhaw.ch/de/engineering/weiterbildung/detail/kurs/wbk-rust-for-embedded-developers):
  an in-person Rust course at the Zurich University of Applied Sciences (German)
- (upcoming) [Flirt](https://blog.buenzli.dev/announcing-development-on-flirt/):
  a code review tool optimized for iterating toward clean history

Maintainer of:

- the official Rust [website](https://www.rust-lang.org) and [blog](https://blog.rust-lang.org)
- [Rustlings](https://rustlings.rust-lang.org/): exercises for practicing Rust syntax

Cool stuff I did:

- I contributed a bunch to the [Jujutsu VCS](https://www.jj-vcs.dev/latest/), including some big features:
  - dynamic completions
  - step-by-step undo & redo
  - auto-tracking bookmarks by pattern
- My first contribution to the Linux kernel was a [safe Rust API for "device properties"](https://blog.buenzli.dev/rust-for-linux-first-contrib/).
- [buenzli.dev](https://buenzli.dev) is my personal domain for nerdy stuff.
  "Bünzli" is a Swissgerman word for "stuck-up person", I use it ironically :)
- [blog.buenzli.dev](https://buenzli.dev) is where I sometimes ramble about stuff I've been working on.
- [buenzliboard](https://www.reddit.com/r/ErgoMechKeyboards/comments/1i4vps3/buenzliboard/) is an ergonomic keyboard I made.
  It features ultra-low profile switches and a custom PCB.
  It's not very good, but I learned a ton.

Cool FOSS software I use:

- [Fedora Linux](https://fedoraproject.org/) for operating my system
- [Fish](https://fishshell.com/) and [Rust](https://rust-lang.org/) for telling my computers what to do
- [Jujutsu](https://www.jj-vcs.dev/latest/) for controlling my versions systematically
- [Helix](https://helix-editor.com/) for editing my text files
- [Niri](https://niri-wm.github.io/niri/) for managing my windows
- [Podma + Quadlet](https://docs.podman.io/en/latest/markdown/podman-systemd.unit.5.html#description) for deploying containers
- [Caddy](https://caddyserver.com/) for handling SSL certificates, serving files and proxying stuff in reverse
- [PocketID](https://pocket-id.org/) for signing into my self-hosted apps
- [Forgejo](https://forgejo.org/) for hosting some personal repos on [git.buenzli.dev](https://git.buenzli.dev)
- [chezmoi](https://www.chezmoi.io/) for managing my dotfiles
- [mise](https://mise.jdx.dev/) for installing project-specific tools, running tasks and background jobs
